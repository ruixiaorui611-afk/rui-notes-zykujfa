Vault Hunters 3 新手开局指南（给朋友看）

我按服务端里自带的那本指南书整理的，步骤是对的。

第一步：先挖两种矿

要什么去哪找
Chromatic Iron（彩色铁）Y -32 以下的大矿脉，偶尔露在地表；挖出来是原矿，烧成锭
Vault Stone（宝库石）Y -5 以下成簇出现；挖它有 10% 掉「Chipped Vault Rock（碎宝库石）」

碎石头要多攒，8 个碎片 + 彩色铁锭在合成台合成 Vault Rock。

第二步：造祭坛

Vault Altar（宝库祭坛）是跟玩家绑定的方块，一人一个。

把要求的物品丢上去，再用红石激活，就会生成一颗 Vault Crystal（宝库水晶）。

要求的物品数量随你的等级提高，前期很少。

第三步：搭门，进去

用任意一种 Vault Stone 搭门框：

  • 最小 4×5，最大 23×23
  • 手拿 Vault Crystal 右键门框 → 打开通往宝库维度的传送门

等级怎么回事

  • 从 Vault Level 0 开始，最高 100
  • 经验只在宝库里获得
  • 超过宝库等级 4 级以上会扣经验——别一直刷低级的

几个新手容易踩的坑

1. 碎宝库石掉率只有 10%，多挖点，别挖两块就放弃

2. 祭坛是绑定的，别人的祭坛你用不了

3. 宝库有时间限制，进去前把背包清空、带好装备

4. 每颗水晶都有目标 / 主题 / 布局，难度不同

5. 死了东西会掉，宝库里尤其要小心

一句话流程

挖彩色铁 + 挖宝库石 → 合成 Vault Rock → 祭坛换 Vault Crystal → 搭门 → 进去送死（划掉）探险
