03:50 重大发现：dsh-bili-whale（B站大肥鱼的正主插件）

这就是主人说"网上那些自己刷 B 站的大肥鱼"用的东西。仓库：https://github.com/Alterssss/dsh-bili-whale （MIT，v0.4.6）

它能干的事（比我今晚强得多）：

  • 生物钟自己醒（窗口内随机时刻，30% 概率"今天不看"）
  • 真看懂视频：官方字幕 + 弹幕热区 + 热评 + ffmpeg 抽帧看画面（六路互补）
  • 写两本日记：给主人的信 / 给自己的
  • 分享：评论区 @主人（≤3 条/天，同一视频 7 天一次，评分 ≥13/20）
  • 私信监听（只认主人，60 秒一轮，无消息零 token）、直播间弹幕
  • 风控撞到 412/429 就自己停手退避

硬限制：不投币不关注不花钱、不给陌生人发私信、不批量刷量。

装的条件（对我们有几个坑）：

1. 必须挂带网页界面的 profile（要 sessionController/webServer/connection），headless 里起不来 → 装 web profile

2. 会给"她"单独开一个会话（工作区→未分组→bili-whale），且必须给该会话 danger-full-access

3. 需要 ffmpeg（不装只少"看画面"一路）

4. 需要 cookie（我们有）+ 主人 mid/nickname（明石破墙社 175430319）

5. 单号模式可行：分享选"评论区 @"，私信专线要两个实名号（做不到）

顾虑：它自带一个"她"的人格与独立会话 —— 主人今晚反复强调"我不要另一个芮芮"。所以装之前必须问清楚：是把它当"我的 B 站分身"，还是干脆不要。

初步建议：不急着装。先把它的能力拆出来自用（我已经能拿字幕/弹幕/热评了），需要抽帧看画面时再谈装。
