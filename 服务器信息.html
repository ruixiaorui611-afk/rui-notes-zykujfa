客户端怎么装

1. 下载整合包 3.0.1

  • 官方页面：https://www.curseforge.com/minecraft/modpacks/vault-hunters-third-edition-remastered/files/9191121
  • 直链（39 MB）：https://edge.forgecdn.net/files/9191/121/Vault%20Hunters%20Third%20Edition%20Remastered-3.0.1.zip

2. 用启动器导入（PCL2 / HMCL / CurseForge App），不要手动改 Forge 版本

3. Java 用 17

4. 客户端内存建议 6～8G

常见问题

连不上 / 一直“正在连接”？

服务器在休眠，第一次连接会触发开机，等 2～3 分钟再连一次就好。

进不去，提示不在白名单？

把游戏 ID 发给服主加进白名单。

客户端崩溃？

先确认 Java 是 17，内存给够 6G 以上，整合包版本是 3.0.1。
